How does the brain represent the visual world?

大脑如何表征视觉世界？

I combine high-throughput electrophysiology in non-human primates with computational models to study how the brain represents the visual world—and how those representations are shaped by experience, scene context, and species.

我结合非人灵长类高通量电生理与计算模型，研究大脑如何表征视觉世界，并探索视觉表征如何受到经验、场景语境与物种差异的调制。

2022–2026 · PUBLISHED · OPEN SOURCE

Triple-N Dataset

Non-human Primate Neural Responses to Natural Scenes

Triple-N is a large-scale neural dataset designed to bridge fine-grained electrophysiology and large-scale neuroimaging in primate vision. Using fMRI-guided Neuropixels recordings, we measured neural responses from five macaques viewing 1,000 natural scenes shared with the human Natural Scenes Dataset.

中文介绍

Triple-N 旨在连接灵长类视觉研究中的高密度单神经元记录与大规模脑成像。我们利用 fMRI 定位并结合 Neuropixels，在 5 只猕猴观看 1,000 张 NSD 自然场景图片时记录视觉皮层神经活动，为跨物种比较提供统一的数据基础。

2024–2026 · IN PREPARATION

Visual Anagrams

Interpretation-dependent object representations in macaque IT cortex

By rotating the same visual elements into different object interpretations, we find that macaque IT population activity systematically shifts between competing object representations.

通过旋转同一组视觉元素形成不同物体解释，我们发现猕猴 IT 群体活动会随支持的物体解释在竞争性物体表征之间系统性移动。

Research Projects

2022–2026 · PUBLISHED · OPEN SOURCE

Triple-N Dataset

Non-human Primate Neural Responses to Natural Scenes

Triple-N is a large-scale neural dataset designed to bridge fine-grained electrophysiology and large-scale neuroimaging in primate vision. Using fMRI-guided Neuropixels recordings, we measured neural responses from five macaques viewing 1,000 natural scenes shared with the human Natural Scenes Dataset.

Dataset & docs ↗Paper ↗VSS talk ↗GitHub ↗

2024–2026 · PREPRINT · BIORXIV

Visual Anagrams

Interpretation-dependent object representations in macaque IT cortex

Visual anagrams depict different objects when rotated. We show that macaque IT population responses shift with the object interpretation supported by each orientation.

Preprint · bioRxiv ↗
